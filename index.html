Mode de fonctionnement

Cette version fonctionne localement, sans abonnement et sans connexion à un service d’intelligence artificielle. Les interprétations utilisent les textes que vous saisissez dans vos fiches. La reconnaissance automatique des cartes et l’interprétation par IA pourront être ajoutées séparément.

Installation sur mon téléphone

Après mise en ligne sécurisée (HTTPS), ouvrez cette application dans Chrome sur Android puis utilisez le bouton ci-dessous si votre navigateur le propose, ou le menu ⋮ puis « Installer l’application » / « Ajouter à l’écran d’accueil ».

Le bouton devient disponible si Chrome autorise l’installation.
